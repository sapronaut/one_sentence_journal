# one sentence

a quiet place for one thought a day.

made this as a small personal journal.  
you write only one sentence each day.  
no pressure, no long entries — just a single line that stayed with you.

features:
- personal onboarding with your name
- daily rotating gentle prompts
- optional mood dots
- soft save sound
- streak celebrations
- clean calendar heatmap
- fully local (localStorage only)

stack:
- vite + react + typescript
- tailwind css
- framer-motion
- date-fns
- lucide-react

structure:

src/
  App.tsx          - main journal + onboarding
  types.ts         - entry & user types
  index.css        - base styles
